# eBR PoC 데모

가상 데이터로 만든 eBR(전자 배치 기록) / eMBR PoC 화면 데모입니다. 실제 고객·설비·사용자 데이터는 들어 있지 않습니다.

## 여는 방법

- 웹에서: GitHub Pages 주소의 `index.html`(카탈로그)을 엽니다. 왼쪽 메뉴에서 화면을 고르면 오른쪽에 표시됩니다.
- 내 PC에서: 저장소를 받은 뒤 `index.html`을 브라우저(Chrome / Edge 권장)로 엽니다.
- 특정 화면 바로 열기: `index.html#s-ebr-equipment-state-ui.html`처럼 `#` 뒤에 화면 파일 이름을 붙입니다.

## 참고

- 화면은 1920×1080 기준이며, 창이 작으면 자동으로 축소됩니다.
- 입력한 데이터는 브라우저 localStorage에만 저장됩니다. 각 화면의 [시드 복원]으로 초기 데이터로 되돌릴 수 있습니다.
