PoC 화면 카탈로그

루트 docs/design/poc/ 아래 백업(*.bak*, bak-*, backup 폴더)을 제외한 실행·작성·기준정보 화면을 한곳에서 엽니다. 왼쪽 메뉴를 선택하면 오른쪽에 미리보기가 로드됩니다.

  • 기본은 환영 화면입니다. 새로고침 후에도 선택 유지: URL 해시 예) #master-setup/guide/s-master-setup-overview-ui.html
  • iframe 미리보기가 깨지면 새 탭으로 열기로 단독 확인하세요.
  • 휴대폰에서는 미리보기 안 화면이 1920px 폭으로 축소됩니다. 새 탭으로 열기로 보세요 (프로세스 트리 디자이너는 휴대폰 레이아웃 지원).
  • 레거시 모놀리스(s-ebmr-master-setup-ui.html)는 참고용이며, 기준정보는 master-setup/ 허브·개별 화면을 사용합니다.
  • 바이오 P0: 바이오 시드(MBR-BIO-DS-01) → 효력 → 오더 핀 → 배치 발행 → 생산 실행. 발행 스냅샷 Phase가 생산 보드에 표시됩니다(없으면 PHASES_TMPL 폴백). 자재 QC는 s-ebr-material-qc-ui.html.
